# 服务器 AI 设置

AI 拆分的服务商、模型和接口地址可在页面右上角的“设置”中调整。API Key 不写入
SQLite，也不发送到浏览器，仅由 Next.js 服务端读取。

## 本地或服务器配置

运行应用的环境中提供一个变量：

```bash
AI_API_KEY=你的模型服务密钥
```

重启服务后，设置面板会显示“服务器 Key 已配置”，可使用“测试 AI 连接”确认
当前服务商、模型和接口地址是否匹配。

支持的请求方式：

- `OpenAI`：默认使用 Responses API 地址。
- `Anthropic / Claude`：默认使用 Messages API 地址。
- `OpenAI 兼容接口`：用于自建网关或兼容服务，可填写模型名与完整接口地址。

## 安全说明

AI 请求由服务端发出，网页不会暴露模型密钥。所有页面与 API 均受登录会话保护，
未登录用户无法触发 AI 调用。

系统采用双人独立账号：两位家庭成员各自拥有独立的工作台，任务、项目、想法、
稍后阅读、打卡记录和设置彼此隔离、互不可见。不开放自由注册，由管理员在设置面板
创建新用户。密码仅保存安全哈希，`AI_API_KEY` 仅由服务器环境变量提供。
