# V3.4 Grok 协作版实施记录

## 目标

让 Grok 作为外部对话助手，复用 Time Planner 已有的任务、忙闲、智能今天、专注、复盘和长期记忆能力；所有写入先展示草稿并由用户确认。网站不新增聊天页面，不保存完整对话，不增加后台调度器。

## 本次范围

### 核心闭环

- 独立、可撤销、可分权限的外部助手 Token。
- 助手读取当前任务、项目、范围忙闲、最近复盘和已确认记忆。
- 助手生成、调整、确认智能今天草稿。
- 任务支持进行中、等待、阻塞，以及完成、部分完成、推迟、放弃结果。
- 助手保存每日/每周复盘和明日下一步。
- 所有外部写入支持防重复键并保留来源。

### 第二阶段增强（与本版本一并交付）

- 项目中的里程碑 → 任务 → 行动三级关系。
- 基于真实任务结果生成每周复盘草稿。
- 用户确认后保存可复用流程模板。
- 提供重复流程候选所需的任务结果和来源数据。

## 用户验收句

1. “帮我安排今天”只生成草稿。
2. “确认”只写入一次。
3. “这个在等供应商，周五再看”保存等待对象和跟进日期。
4. “今天只做了一半，明天继续”保存部分完成和下一步。
5. “帮我复盘本周”只根据真实记录生成草稿。
