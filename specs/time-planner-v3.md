# Time Planner V3

## JTBD

让每位独立用户在一个工作台内完成“快速收集 -> 安排今天 -> 专注执行 -> 每日/每周复盘”，并让智能安排在用户可见、可纠正、可删除的结构化记忆基础上逐渐个性化。

## 范围

在 VPS 最新源码上交付 V3.1 快速收集与搜索、V3.2 智能安排与专注执行、V3.3 复盘与长期记忆，并保留现有双账号、周计划、项目、习惯、想法、阅读、Hermes 和 SSE 行为。

## V3.1 快速收集与搜索

- 登录后任意页面可用 `Ctrl/Cmd+K` 打开命令面板，支持键盘关闭和选择。
- 可快速创建未排期任务、想法和稍后阅读链接。
- `/inbox` 聚合未完成且未排期无项目任务、想法、未读阅读项，并按类型筛选。
- `/search` 和 `/api/search` 检索任务、项目笔记、想法、阅读标题/URL/备注，最多返回 50 条。
- 所有结果严格限制为当前用户，未登录 API 返回 401。

## V3.2 智能安排今天与执行

- 任务支持预计分钟、精力等级、偏好时段和完成时间；旧任务字段可为空。
- `/today` 展示逾期、当日和本周未排期候选任务，生成不重叠且不超容量的计划草案。
- 默认确定性规则可独立运行；AI 只提供排序/解释，失败或非法输出时自动回退。
- 草案不会直接修改任务；用户可接受、拒绝、移动，确认后才安排日期。
- 专注会话支持开始、刷新恢复、停止和当日累计，同一用户最多一个运行会话。
- 所有生成、确认、拒绝、移动、专注和完成动作记录结构化反馈。
- Hermes 提供晨间、逾期、晚间只读摘要接口，不在应用内增加定时任务。

## V3.3 复盘、长期记忆与可靠性

- `/review` 提供每日/每周统计和文字复盘，单用户单周期幂等更新。
- 显式结转：P1 移到次日，P2/P3 退回本周待办；重复执行不重复变更。
- 展示停滞项目和下一步行动建议。
- 统计计划数、完成数、预计分钟、专注分钟和习惯完成率；历史缺失数据不伪造。
- 结构化记忆包含显式设置、偏好、行为、近期上下文、证据数、置信度、确认状态和过期时间。
- 用户可查看、确认、修改和删除自己的记忆；一次行为不会直接固化长期偏好。
- 用户可导出自己的非敏感数据及校验摘要，不包含密码、会话、Hermes Token、AI Key 或其他用户数据。

## 共同约束

- 现有用户和数据不可丢失；迁移可重复执行。
- 所有实体关系同时验证 `user_id`，不得仅凭 ID 访问。
- 日期按 `Asia/Shanghai`；GET 请求不得产生结转、确认或完成等隐藏副作用。
- 生产数据库只在部署前备份后迁移；开发和预览使用临时数据库。
- 不实现团队协作、CalDAV、PWA、自动桌面监控或复杂后台调度。

## 验收标准

- 两个测试账号的搜索、收件箱、计划、专注、反馈、复盘、记忆和导出互不可见。
- 原有任务/项目/周计划/习惯/想法/阅读/Hermes API 正常运行。
- AI 缺失和 AI 非法返回均能生成规则草案。
- 结转、计划确认、复盘保存和迁移均幂等。
- 自动化测试、TypeScript 检查、Next.js 生产构建通过。
- VPS 预览端口通过登录、核心流程和健康检查后，才允许备份并切换生产。
